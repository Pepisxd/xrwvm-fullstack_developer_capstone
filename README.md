# fullstack_developer_capstone

Best Cars dealership portal — IBM Full Stack Application Development Capstone Project.

- **Django** app (`server/djangoapp`, `server/djangoproj`) with a **React** front end (`server/frontend`)
- **Express + MongoDB** backend for dealers and reviews (`server/database`)
- **Flask/NLTK** sentiment analyzer microservice (`server/djangoapp/microservices`)
- Containerized and deployed to **Kubernetes** (`server/Dockerfile`, `server/deployment.yaml`)
- CI linting with **GitHub Actions** (`.github/workflows/main.yml`)
